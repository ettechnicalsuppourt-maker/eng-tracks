# Engineering Tracks Landing Page

Official responsive, high-performance landing page for **[Engineering Tracks](https://engineering-tracks.com/)** — Accredited Engineering & Management Training Academy in Egypt, Saudi Arabia, and the Gulf.

## 🚀 Features
- **16 Professional Engineering Tracks**: Every track includes dedicated photography, course counts, and core certification tags.
- **Flagship Courses & Pricing**: Live dynamic currency conversion for **SAR (﷼)**, **EGP (ج.م)**, and **USD ($)**.
- **Bilingual Interface**: Seamless switch between **English (LTR)** and **العربية (RTL)** with localized Arabic branding.
- **Dark & Light Mode**: High-contrast engineering design system with persistent `localStorage` preference.
- **Interactive Exam Simulator**: Timed Pearson VUE style test question engine with instant rationale explanation.
- **Regional Branches**: Contact cards with direct links for Cairo (Egypt), Al-Khobar (Saudi Arabia), and Sharjah (UAE).
- **Social Media Channels**: Direct connections to Facebook, YouTube, Twitter/X, Instagram, and LinkedIn.

## 📁 Tech Stack
- Semantic HTML5
- Vanilla CSS3 Design System
- Vanilla JavaScript (ES6+)
