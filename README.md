# Engineering Tracks Landing Page (Vue 3 + Vite)

Official modern, responsive, and high-performance web application for **[Engineering Tracks](https://engineering-tracks.com/)** — Accredited Engineering & Management Training Academy in Egypt, Saudi Arabia, and the Gulf.

---

## 🚀 Features
- **Vue 3 Composition API (`<script setup>`)**: Fully reactive state management for themes, language, currency, filters, modals, and quiz engine.
- **16 Professional Engineering Tracks**: Every track includes dedicated photography, course counts, and core certification tags.
- **Flagship Courses & Pricing**: Reactive multi-currency pricing for **SAR (﷼)**, **EGP (ج.م)**, and **USD ($)**.
- **Bilingual Support (English LTR & العربية RTL)**: Seamless instant switch with bidirectional typography (Inter/Outfit for English, Cairo for Arabic).
- **Dark & Light Mode**: High-contrast engineering design system with persistent preference.
- **Interactive Exam Simulator**: Timed Pearson VUE style test question engine with instant rationale explanation.
- **Mobile Responsive Drawer & Menus**: Optimized touch-first navigation drawer with quick contact and currency selector.
- **Regional Branches**: Contact cards with direct links for Cairo (Egypt), Al-Khobar (Saudi Arabia), and Sharjah (UAE).
- **Official Social Media**: Integrated links to Facebook, YouTube, Twitter/X, Instagram, and LinkedIn.

---

## 🛠️ Tech Stack
- **Framework**: [Vue 3](https://vuejs.org/) (Composition API)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS Design System with CSS Custom Properties and Smooth Transitions
- **Icons**: Font Awesome 6
- **Typography**: Google Fonts (Outfit, Inter, Cairo)

---

## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally (Dev Server)
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in `dist/`.

### 4. Preview Production Build
```bash
npm run preview
```
